# 🎧 SongHub

SongHub is an unofficial web client for exploring and searching songs from Song File Hub.

## Features

- 🔎 Search by song name, artist, Newgrounds ID and Song File Hub ID
- ▶ Play songs directly from Song File Hub
- 📋 Copy audio links
- ⚡ Fully static website (HTML + JS)
